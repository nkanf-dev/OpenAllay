# OpenAllay v0.4.0

## English

OpenAllay 0.4.0 adds richer session controls, image-aware conversations, a redesigned in-game interface, and optional voice input for Minecraft gameplay.

### Sessions and context

- **See actual usage.** The fullscreen chat now reports available context and session usage from provider-reported data where available. Cache rates use available reported usage, while costs use captured reference prices. Missing or incomplete usage/pricing stays unknown or partial, not zero. An estimate is not a bill.
- **Branch a completed task.** Fork a completed task into an independent conversation from its finalized history. A fork does not replay the original tools or repeat world actions.
- **Control active work.** Queue a Follow-up to start after the active task releases its resources, or send Steer guidance for the next operation boundary. Steer does not interrupt an in-flight model call.
- **Compact on demand.** Use `/compact` while the conversation is idle to summarize older context with your client-configured model, without submitting a new gameplay task.
- **Work with images.** Paste images with Ctrl/Cmd+V into supported model requests, and retain image content with session history and export. Image support depends on the selected model and provider.

### A clearer in-game interface

- **Fullscreen chat.** The composer, status and request controls have been refined. Click outside the text input to release focus; click it again to resume typing.
- **Tool results.** Compact tool cards keep the conversation readable. Click a card to open the detail drawer; item and recipe controls remain directly accessible without opening the parent card.
- **HUD reading.** The passive HUD follows the latest result instead of cycling through pages. Open the interactive reader to browse longer content and return to the latest section.
- **Settings and feedback.** Settings apply before the screen closes, with drafts retained when validation or saving fails. Native notifications show the actual tool title and description, with clearer action guidance.
- **Usage details.** A structured tooltip explains context and session usage without clipping long values.

### Optional voice input

- **Gameplay push-to-talk.** When voice input is enabled and configured, hold the assigned key in gameplay or the HUD to capture speech. Choose whether the transcript is sent immediately or placed in the editable draft. Fullscreen voice input remains draft-first. The default voice key is unbound; configure it in Minecraft Controls.
- **Local Native or HTTP backend.** Native speech recognition requires a compatible model to be installed or imported. The optional HTTP backend requires a compatible service and configuration. Voice input is disabled by default.
- Recording is explicit and bounded by the configured clip limit. OpenAllay does not use always-on capture or automatically retry recording. Choose a microphone and recognition model that suit your language and environment.

### Compatibility

- Supports Minecraft **26.2** on **Java 25**, with Fabric and NeoForge distributions.
- OpenAllay product version: **0.4.0**. Public Extension API remains **0.2.2**. Bundled Minecraft Builder: **0.2.1**, with updated OpenAllay 0.4.x compatibility.
- Before upgrading, back up your configurations and session history. Pre-1.0 internal formats are latest-only; incompatible older files are preserved, not automatically migrated.

## 简体中文

OpenAllay 0.4.0 带来更丰富的会话控制、图片对话、重新整理的游戏内界面，以及可选的 Minecraft 玩法语音输入。

### 会话与上下文

- **查看实际用量。** 全屏对话界面会在服务商提供数据时显示上下文与会话用量。缓存命中率来自可用的服务商用量，费用使用记录时的参考价格估算；用量或价格缺失、不完整时保持“未知”或部分数据，而不是零。估算不是账单。
- **从已完成任务创建分支。** 从已完成任务的最终历史创建独立会话；分支不会重放原任务的工具调用，也不会重复执行世界操作。
- **控制正在进行的任务。** 可将“跟进”排入队列，在当前任务释放资源后开始；也可发送“引导”，在下一个操作边界补充指令。“引导”不会中断正在进行的模型调用。
- **按需整理上下文。** 会话空闲时使用 `/compact`，通过客户端配置的模型摘要旧上下文，不提交新的游戏任务。
- **使用图片。** 可用 Ctrl/Cmd+V 为支持图片的模型请求粘贴图片，并随会话历史和导出保留图片内容。具体能力取决于所选模型与服务商。

### 更清晰的游戏内界面

- **全屏对话。** 优化输入框、状态和请求控制。点击文本输入框外可取消焦点，再次点击即可继续输入。
- **工具结果。** 紧凑工具卡让对话更清楚；点击卡片打开详情抽屉；卡片内物品与配方操作优先响应，不误触父卡片。
- **HUD 阅读。** 被动 HUD 跟随最新结果，不再循环翻页。打开交互阅读器可浏览长内容，并随时返回最新位置。
- **设置与反馈。** 设置保存后才关闭页面；校验或保存失败时保留草稿。原生通知显示实际工具标题和描述，并提供更清晰的操作提示。
- **用量详情。** 结构化提示框展示上下文与会话用量，避免长数据被截断。

### 可选语音输入

- **玩法中的按住说话。** 启用并配置语音输入后，可在游戏过程中或 HUD 中按住指定按键录音。可选择立即发送识别结果，或放入可编辑草稿；全屏语音输入仍先写入草稿。默认语音按键未绑定，请在 Minecraft 控制设置中配置。
- **本地 Native 或 HTTP 后端。** Native 语音识别需要安装或导入兼容模型。可选 HTTP 后端需要兼容服务及相应配置。语音输入默认关闭。
- 录音由用户明确触发，并受设置的录音时长限制。OpenAllay 不会持续监听，也不会自动重试录音。请根据语言和使用环境选择麦克风及识别模型。

### 兼容性

- 支持 **Minecraft 26.2**、**Java 25**，提供 Fabric 与 NeoForge 发行包。
- OpenAllay 本体版本：**0.4.0**；公共 Extension API 保持 **0.2.2**。内置 Minecraft Builder 为 **0.2.1**，兼容 OpenAllay 0.4.x。
- 升级前请备份配置和会话历史。1.0 前内部格式仅维护最新形态；不兼容的旧文件会保留，不会自动迁移。
