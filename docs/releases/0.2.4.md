# OpenAllay v0.2.4

## English

- **Easier model setup.** A built-in offline model table can fill in a supported
  model's context window automatically. You can still set your own context window.
- **Model price references.** The Models page now shows published token prices and price
  tiers, together with their sources and dates.
- **Clearer tool cards.** JavaScript steps show a short title and description of
  the planned work. These descriptions also stay with saved conversations.
- **More useful game UI.** Controls fit smaller windows, source details show where
  information came from, and stopped steps and retries have clearer status text.
- **Builder included.** Both loader downloads now include the Minecraft Builder
  Extension. Enable unrestricted JavaScript to build in your single-player world
  with six presets, structure templates, rotation, mirroring, and block undo.
- **Smoother provider responses.** OpenAI-compatible responses now handle empty
  optional tool and usage fields correctly, so answers can finish normally.

## 简体中文

- **模型配置更轻松。** 内置离线模型表可为支持的模型自动填写上下文窗口，
  也支持按需手动设置。
- **模型价格更直观。** 模型设置显示公开的 Token 参考价格、价格档位，以及来源和日期。
- **工具卡片更清晰。** JavaScript 步骤用简短标题和说明展示计划执行的工作，
  保存的会话也会保留这些说明。
- **游戏界面更好用。** 操作按钮适配更小的窗口，来源详情展示信息出处，
  已停止的步骤与重试操作也有更清楚的状态说明。
- **默认包含建筑扩展。** 两种加载器的下载包均包含 Minecraft Builder 扩展。
  开启无限制 JavaScript 后，即可在单人世界使用六种建筑预设、结构模板、旋转、镜像和方块撤销。
- **模型响应更顺畅。** 修复 OpenAI 兼容服务返回空的可选工具或用量字段时的处理，
  让回答正常完成。
