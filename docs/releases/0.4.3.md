# OpenAllay 0.4.3

## More Forge modpacks

OpenAllay now supports Forge on Minecraft **1.18.2** and **1.19.2**. Existing Fabric and NeoForge versions remain available. Use Java 17 for these two Forge versions and install the JAR that matches your Minecraft version and loader.

## Model setup and typing fixes

- Settings preserve complete URLs, model names, and API keys when you reopen a profile or confirm a connection test.
- Connection tests use the values currently entered in the editor. You can test a new key before saving it.
- The initial model profile uses automatic token budgets, like a new profile.
- Space stays in the text editor for typing and input-method candidate selection. Enter sends; Shift+Enter inserts a new line.

## Clearer HUD

The HUD shows the task title, useful results, and readable progress. Execution records and sources remain available in task details. Completed previews reuse cached text instead of scanning the same conversation again.

## Download

Choose your Minecraft version and loader from the release assets. Install only one OpenAllay JAR in `mods`. Keep your worlds and existing OpenAllay configuration when updating.

# OpenAllay 0.4.3

## 支持更多 Forge 整合包

新增 Minecraft **1.18.2** 和 **1.19.2** 的 Forge 支持，原有 Fabric 和 NeoForge 版本继续提供。这两个 Forge 版本使用 Java 17，请下载与 Minecraft 版本和加载器匹配的安装包。

## 模型设置和输入修复

- 重新打开配置或确认连接测试时，完整保留 URL、模型名和 API key。
- 连接测试使用编辑框当前填写的内容，新 key 无需先保存就能测试。
- 初始模型配置与新增配置一样使用自动 token 预算。
- 空格保留给文本输入和输入法选字。Enter 发送，Shift+Enter 换行。

## 更清楚的 HUD

HUD 优先显示任务名称、有用的结果和易懂的进度。执行记录和来源仍可在任务详情中查看。已完成的回复复用缓存文本，减少重复扫描。

## 下载和更新

按 Minecraft 版本和加载器选择安装包，在 `mods` 中只安装一个 OpenAllay JAR。更新时保留世界和现有 OpenAllay 配置。
