# OpenAllay v0.4.2

## English

OpenAllay 0.4.2 brings OpenAllay to **23 Minecraft versions from 1.20.1 through
26.3**, on both **Fabric and NeoForge**.

### Download and install

1. [Download OpenAllay 0.4.2](https://github.com/nkanf-dev/OpenAllay/releases/tag/v0.4.2).
2. Choose the JAR for your Minecraft version and loader. Some files support more
   than one version; [see the full download table](https://github.com/nkanf-dev/OpenAllay/blob/main/docs/native-binary-artifacts.md#published-042-files).
3. Put the JAR in your instance's `mods` folder. On Fabric, also install the
   matching Fabric API.

| Minecraft | Java |
| --- | --- |
| 1.20.1–1.20.4 | 17 |
| 1.20.5–1.20.6 and 1.21–1.21.11 | 21 |
| 26.1, 26.1.1, 26.1.2, 26.2, 26.3 | 25 |

### What changed

- **Builder is easier to enable.** Turn on Minecraft Builder in Settings →
  Extensions to use its building tools. There is no separate world-write switch.
- **Full access includes commands and enabled Extensions.** Minecraft server
  rules and your player's permissions still apply.
- **Follow-up requests are more reliable.** Fixed a timing issue when starting
  a follow-up after the previous request finished.

For Extension authors, this release includes **Extension API 0.4.0** and
**Minecraft Builder 0.4.0**. [See the development guide](https://github.com/nkanf-dev/OpenAllay/blob/main/docs/development.md)
for integration details.

## 简体中文

OpenAllay 0.4.2 现已支持 **从 Minecraft 1.20.1 到 26.3 的 23 个版本**，
覆盖 **Fabric 和 NeoForge**。

### 下载与安装

1. [下载 OpenAllay 0.4.2](https://github.com/nkanf-dev/OpenAllay/releases/tag/v0.4.2)。
2. 选择适合你的 Minecraft 版本和加载器的 JAR。部分文件支持多个版本，
   具体见[完整下载表](https://github.com/nkanf-dev/OpenAllay/blob/main/docs/native-binary-artifacts.md#published-042-files)。
3. 把 JAR 放进游戏实例的 `mods` 文件夹。使用 Fabric 时，还需安装匹配的 Fabric API。

| Minecraft 版本 | Java 版本 |
| --- | --- |
| 1.20.1–1.20.4 | 17 |
| 1.20.5–1.20.6，以及 1.21–1.21.11 | 21 |
| 26.1、26.1.1、26.1.2、26.2、26.3 | 25 |

### 本次改进

- **Builder 开启更简单。** 在设置 → 扩展中启用 Minecraft Builder，即可使用
  建造工具，不再需要单独打开世界写入开关。
- **完整访问包含命令和已启用扩展的操作。** Minecraft 服务端规则和玩家权限
  仍然适用。
- **跟进请求更可靠。** 修复了上一条请求结束后发起跟进时的时序问题。

扩展开发者可使用本次配套的 **Extension API 0.4.0** 和 **Minecraft Builder 0.4.0**。
接入方式见[开发指南](https://github.com/nkanf-dev/OpenAllay/blob/main/docs/development.md)。
