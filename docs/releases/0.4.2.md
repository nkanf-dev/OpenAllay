# OpenAllay v0.4.2

## English

OpenAllay 0.4.2 updates player permissions, Extension integration, and Minecraft release packaging.

- Full access includes lower permission levels. Enabled Builder capabilities use the player's authorization instead of a separate private write gate.
- The shared feature engine stays separate from Minecraft-native code. Minecraft 26.2 is the feature mainline.
- The Minecraft world adapter module is named `adapters/minecraft` (`:adapters:minecraft`). It reuses a shared base with native-family overrides through one SDK. Java factory/package names stay unchanged; source reuse does not establish a wider same-JAR support range.
- Release files are grouped by loader and verified binary-compatible Minecraft interval. Use the exact Minecraft versions listed on each download.
- A released request no longer remains available for follow-up admission during the event handoff.
- Product version **0.4.2**; public Extension API **0.4.0**; bundled Minecraft Builder **0.4.0**. These are independent version coordinates.

Fabric requires the matching Fabric API. Published v0.4.1 tags, notes, and downloads remain unchanged.

## 简体中文

OpenAllay 0.4.2 更新玩家权限、Extension 集成与 Minecraft 发布打包。

- 完整访问权限涵盖较低权限。已启用的 Builder 能力遵循玩家授权，不再使用独立的私有写入门槛。
- 共享功能引擎与 Minecraft 原生代码保持分离。Minecraft 26.2 是功能主线。
- Minecraft 世界适配模块改为 `adapters/minecraft`（`:adapters:minecraft`），通过同一套 SDK 复用共享基础实现与原生家族覆写。Java 工厂与包名保持不变；源码复用不等于同一 JAR 已支持更宽的游戏版本范围。
- 发布文件按加载器与已验证的二进制兼容 Minecraft 区间合并。请以每个下载文件列出的准确 Minecraft 版本为准。
- 已释放的请求不再在事件交接期间接受后续请求。
- 本体版本 **0.4.2**；公共 Extension API **0.4.0**；内置 Minecraft Builder **0.4.0**。三者使用独立版本坐标。

Fabric 需要匹配的 Fabric API。已发布的 v0.4.1 标签、说明与下载文件保持不变。
