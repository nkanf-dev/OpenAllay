# OpenAllay 0.4.4

[English](#english) · [简体中文](#简体中文)

## English

### Your companion in older Forge modpacks

OpenAllay now supports **Forge 1.16.5 and 1.12.2**, alongside Forge 1.18.2 and
1.19.2 and Fabric/NeoForge 1.20.1 through 26.3. Explore game data, ask about
recipes and installed content, and use the shared Agent workflows in your
chosen instance.

- **Forge 1.16.5:** use Forge **36.2.42**, **Java 17**, and the matching OpenAllay
  JAR in `mods`.
- **Forge 1.12.2:** install stock **Forge 14.23.5.2864**, then download the GitHub
  ZIP. Run its installer with **Python 3.11 or later**. The default check writes
  no files; add `--install` to create a new profile. Select it and **Java 17** in
  your launcher, then sign in normally.

See the [Forge installation guide](../forge-runtime-installation.md) and
[complete file table](../native-binary-artifacts.md#release-044-files).

### Build in your single-player world

Enable **Minecraft Builder** in **Settings → Extensions** to use geometry,
terrain tools, structure templates, and available presets in your active
single-player world. Building works in ordinary JavaScript mode; the
**Enable full-access JavaScript** switch can stay off.

- **1.16.5:** geometry, decoration, terrain, templates, house, cottage,
  windmill, farm, and dock. The skyscraper preset needs a lightning rod.
- **1.12.2:** geometry and native block variants, terrain paths, persisted
  templates, rotation and mirroring, and block undo. Use these operations
  with its available materials. The six structure presets require materials
  outside this version's palette.

Cancellation retains blocks already placed. Undo restores matching recorded
changes and reports conflicts with later edits.

### Community Skills for your active instance

Open **Settings → Skills → Community** and refresh the catalog to browse
workflows compatible with your Minecraft version. Community workflows cover recipe diagnosis, machine usage,
quest progression, guide-book search, game-state inspection, and commands.
The command Skill now uses the host's native catalog and item syntax, including
Minecraft 1.12.2's partial client-local catalog and older item NBT.

Extension authors can use public **Extension API 0.4.0**. Downloads include
**Builder 0.4.0**; community Skills use **Skill API 0.2** compatibility.

### Downloads

GitHub provides **34 JARs and one Forge 1.12.2 ZIP**, covering **27 Minecraft
versions and 50 version/loader pairs**. Modrinth provides the **34 JARs**, covering
**26 Minecraft versions and 49 pairs**. Fabric requires the matching Fabric API.
Select the Java runtime listed in the compatibility table.

## 简体中文

### 在旧版 Forge 整合包中使用你的 AI 伙伴

OpenAllay 新增 **Forge 1.16.5 和 1.12.2** 支持，并继续支持 Forge 1.18.2、
1.19.2，以及 Fabric/NeoForge 1.20.1 到 26.3。你可以在自己的游戏实例中查询数据、
询问配方和已安装内容，使用共享的 Agent 工作流。

- **Forge 1.16.5：**使用 **Forge 36.2.42、Java 17**，将对应 OpenAllay JAR 放入 `mods`。
- **Forge 1.12.2：**先安装原版 **Forge 14.23.5.2864**，再从 GitHub 下载 ZIP。
  使用 **Python 3.11 或更新版本**运行安装器。默认检查不写文件；加上 `--install`
  创建新配置。在启动器中选中它和 **Java 17**，然后正常登录。

详细步骤见[Forge 安装指南](../forge-runtime-installation.md)，
文件对应关系见[发布兼容表](../native-binary-artifacts.md#release-044-files)。

### 在单人世界里建造

在**设置 → 扩展**中启用 **Minecraft Builder**，即可在当前单人世界里使用几何体、
地形工具、结构模板和可用预设。建造使用普通 JavaScript 模式；
**启用全权限 JavaScript** 开关可以保持关闭。

- **1.16.5：**几何体、装饰、地形、模板，以及房屋、小屋、风车、农场和码头。
  摩天楼预设需要避雷针。
- **1.12.2：**几何体、原生方块变种、地形路径、持久保存的模板、旋转、镜像和方块撤销。
  可配合该版本中的材料使用这些操作。六种建筑预设需要该版本材料表以外的材料。

取消操作会保留已经放置的方块。撤销恢复仍匹配记录的改动，并报告后续编辑造成的冲突。

### 为当前实例选择社区 Skills

打开**设置 → Skills → 社区**并刷新目录，即可浏览兼容当前 Minecraft 版本的工作流。
社区工作流覆盖配方诊断、机器使用、任务进度、指南书搜索、游戏状态检查和命令。
命令 Skill 现在使用对应主机的原生命令目录与物品语法，包括 Minecraft 1.12.2
的客户端局部命令目录和旧版物品 NBT。

扩展作者可使用公共 **Extension API 0.4.0**。下载包包含 **Builder 0.4.0**；
社区 Skills 按 **Skill API 0.2** 检查兼容性。
