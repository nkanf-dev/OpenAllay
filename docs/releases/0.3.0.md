# OpenAllay v0.3.0

## English

### More useful context and clearer results

- **Large results stay usable.** Full game datasets stay in request-scoped
  workspaces instead of filling the model conversation. The model receives a
  budgeted view with size, structure, samples, omissions, and handle lifetime.
  Whole-request checks also cover tool exchanges and summarization requests.
- **Offline BPE token accounting.** OpenAllay now uses JTokkit rather than a
  bytes-to-token ratio. Counts are exact for plain text under the selected
  encoding; whole-request and unknown-model counts remain labelled estimates.
  No tokenizer download or native library is needed at runtime.
- **Clearer result previews.** Result cards distinguish a completed calculation
  from the sample shown on screen. A small preview no longer looks like only
  part of the calculation ran.
- **Context and usage at a glance.** The chat footer shows the latest matching
  context estimate and input budget, provider-reported input/output tokens, and
  reference cost estimates when data is available. Missing usage or prices stay
  unknown; reference prices are not a provider bill.
- **Skills retain their place.** Skill instruction coverage is tracked across
  requests in the same session. Already-retained ranges can be reused without
  inserting the same text again. Changed documents and missing ranges can be
  loaded again, and actual tool calls remain visible.

### Builder with a separate world-action grant

- **Build without unrestricted JavaScript.** The bundled Minecraft Builder uses
  scoped native Extension methods. Enable its separate world-write grant in
  Extension settings to change your single-player world. The grant is off by
  default and does not give the Agent arbitrary Java/JVM access.
- **Less repeated native work.** Builder batches terrain reads and placements,
  skips regions proven to contain only vanilla air, and streams operation
  journals. `update_connections` repairs connection shapes;
  `sync_physics` explicitly requests the broader physics notification pass.
  These reduce repeated work, not guarantee a particular in-game speedup.

### More reliable execution

- **Recover from temporary provider failures.** Retryable upstream errors,
  including HTTP 502, retry the same model round before response progress.
  Recovery respects cancellation, `Retry-After`, and the remaining request
  deadline. It does not rerun completed game tools.
- **Use the runtime's native interfaces.** JavaScript schema inspection, native
  `Array(...)` construction, String allocation guards, and read-only host JSON
  now follow the existing Rhino/Gson contracts more closely.
- **Preserve history and current settings.** Failed history writes remain
  pending for later persistence, and context reads respect captured writes.
  Older asynchronous settings completions no longer replace newer committed
  runtime settings.
- **Keep task data intact.** Generic sensitive-content scanning and redaction
  have been removed from player/tool results. Authorized data is not rewritten
  just because a field is named `token` or `password`. Framework-owned
  credentials are kept out of ordinary context by design, and provider-private
  reasoning is excluded by typed projection.
- **Control reasoning per model.** Model profiles can request provider-specific
  reasoning effort. Automatic mode leaves the provider field unset. Explicit
  settings depend on model/gateway support and do not implicitly enable
  thinking or assign a thinking-token budget.

### Compatibility

- Minecraft **26.2**, Java **25**, with separate **Fabric** and **NeoForge**
  downloads. Both downloads include Minecraft Builder.
- OpenAllay product version: **0.3.0**. Public Extension API: **0.2.2**.
  Bundled Minecraft Builder: **0.2.0**.
  These versions are independent. Extension loader dependencies must accept
  product 0.3.0 separately from their API compatibility range.
- Use the bundled Builder or an independently published compatible build.
  Older Builder packages whose product range excludes 0.3.0 cannot load
  with this release. Remove an older separately installed Builder JAR when
  using the bundled copy.

## 简体中文

### 更实用的上下文与更清楚的结果

- **大结果不再挤满上下文。** 完整游戏数据保留在请求级工作区，模型只接收预算内的视图，
  包括规模、结构、样本、省略说明及句柄有效期。整次请求的预算检查同时覆盖工具交互与摘要请求。
- **离线 BPE Token 统计。** 使用 JTokkit 替代字节数与 Token 数的粗略换算。
  选定编码下的纯文本计数是精确值；整次请求和未知模型的计数仍明确标为估算。
  运行时不需要下载分词器，也不需要原生库。
- **结果预览不再误导。** 结果卡明确区分“计算已完成”与“当前仅显示样本”，
  不再让少量预览看起来像只完成了部分计算。
- **上下文与用量一眼可见。** 聊天底栏显示最近一次匹配请求的上下文估算及输入预算、
  服务商报告的输入/输出 Token，以及数据足够时的参考费用。
  缺失用量或价格保持“未知”，参考费用不是服务商账单。
- **Skill 加载状态可复用。** 同一会话跨请求追踪实际保留的指令范围，
  已存在的内容可直接复用，不再重复插入正文。文档变化或内容缺失时可重新加载，真实工具调用仍然可见。

### Builder 使用独立的世界操作授权

- **建筑不再要求无限制 JavaScript。** 内置 Minecraft Builder 通过受限的原生扩展接口工作。
  在扩展设置中单独授予世界写入权限后，即可修改单人世界。
  该权限默认关闭，不会把任意 Java/JVM 访问能力授予 Agent。
- **减少重复的原生工作。** Builder 批量读取地形与放置方块，跳过已证明仅含原版空气的区域，
  并流式写入操作日志。`update_connections` 负责连接形状修复，
  `sync_physics` 显式触发更广泛的物理通知。这些改动减少重复工作，不承诺具体的游戏内加速倍数。

### 执行更可靠

- **恢复临时服务商故障。** 包括 HTTP 502 在内的可重试上游错误，
  会在尚未开始返回内容时重试同一模型轮次。恢复过程遵守取消操作、`Retry-After`
  和剩余请求时限，不会重新执行已经完成的游戏工具。
- **复用运行时原生接口。** JavaScript 结构检查、原生 `Array(...)` 构造、
  String 分配保护及只读宿主 JSON 更准确地遵循现有 Rhino/Gson 接口约定。
- **保留历史与最新设置。** 历史写入失败后，待写内容会保留供后续落盘；
  上下文读取遵守已捕获写入的顺序。旧的异步设置回调不再覆盖较新的已提交运行时设置。
- **保持任务数据原样。** 移除玩家与工具结果上的通用敏感内容扫描与改写。
  已授权的数据不会仅因字段名是 `token` 或 `password` 而被修改。
  框架持有的凭据从结构上避免进入普通上下文，服务商私有推理通过类型化投影排除。
- **按模型设置推理强度。** 模型配置可请求服务商特定的推理强度，自动模式不发送该字段。
  显式选项取决于模型和网关支持，不会隐式开启 thinking 或分配 thinking Token 预算。

### 兼容性

- 支持 Minecraft **26.2**、Java **25**，分别提供 **Fabric** 与 **NeoForge** 下载包，
  两者均内置 Minecraft Builder。
- OpenAllay 产品版本为 **0.3.0**，公共 Extension API 为 **0.2.2**，
  内置 Minecraft Builder 为 **0.2.0**，各自独立版本化。
  扩展除了满足 API 范围，还必须在加载器依赖中允许产品版本 0.3.0。
- 使用内置 Builder 或独立发布的兼容版本。产品依赖上限排除 0.3.0 的旧 Builder 无法加载。
  使用内置版本时，请移除之前单独安装的旧 Builder JAR。
