# OpenAllay v0.3.0

## English

### Smarter Context and Cleaner Previews

- **Large datasets stay responsive.** Game data queries and tool outputs stay within a budgeted workspace rather than overflowing model context. Complex searches over recipes and items no longer cause token limits or dropped conversations.
- **Precise offline token counting.** Integrated offline BPE token counting accurately measures token usage without needing runtime downloads or external tokenizer libraries.
- **Clean result cards.** Tool cards show completed execution states clearly, with readable expandable views for large result sets.
- **Context capacity and usage at a glance.** The chat footer displays context usage, cache hit rate, and session cost estimates based on published rates.
- **Reusable Skill guidance.** Frequently used Skill instructions are tracked efficiently across requests in the same session, avoiding duplicate text injection while keeping tools visible.

### Dedicated World-Action Controls for Builder

- **Build without unrestricted JavaScript.** The bundled Minecraft Builder uses scoped native Extension methods. You can enable building in single-player worlds with an independent setting, without granting arbitrary JVM or script access.
- **Optimized building performance.** Builder batches block reads and placements, skips empty air volumes, and journals changes cleanly for reliable block undo.

### More Reliable Execution

- **Recover from temporary provider failures.** Retryable upstream errors, including HTTP 502, automatically retry the same model round before partial answers stream, without repeating completed game actions.
- **Preserve history and current settings.** Failed history writes remain pending for later persistence, ensuring newer runtime settings and conversation records are always preserved in order.
- **Keep task data intact.** Generic sensitive-content scanning and keyword redaction have been removed, ensuring normal item names and commands are never modified.
- **Control reasoning per model.** Model profiles can request provider-specific reasoning effort where supported by your model and gateway.

### Compatibility

- Supports Minecraft **26.2** on **Java 25**, with separate packages for **Fabric** and **NeoForge**. Both packages include Minecraft Builder.
- OpenAllay product version: **0.3.0**; public Extension API: **0.2.2**; bundled Builder: **0.2.0**.
- Built-in Builder is ready to use out of the box. Please remove any previously installed older Builder JARs when using the bundled copy.

## 简体中文

### 更智能的上下文与更清晰的交互

- **海量数据查询不再超出上下文。** 大规模游戏数据和复杂结果保留在安全的工作区中，不再轻易撑爆模型对话上下文。查询大量配方、物品或方块时更流畅稳定。
- **精确的离线 Token 统计。** 内置离线 BPE 分词算法，本地精确统计用量与预算，无需额外下载模型或外部库。
- **利落直观的操作卡片。** 工具执行结果清晰展现完成状态，数据量较大时自动提供整洁的折叠展开视图。
- **容量与用量一目了然。** 聊天底栏直观展示上下文预算、缓存命中率以及基于公开单价的费用估算。
- **Skill 工作流高效复用。** 同一会话跨轮次复用已加载的 Skill 指导，避免重复插入冗余文本，保持工具调用清晰可见。

### Builder 世界建造独立授权

- **更安全的建造体验。** 内置 Minecraft Builder 采用独立的原生接口。在扩展设置中单独开启单人世界写入权限即可开始建造，无需开放无限制脚本或 JVM 权限。
- **流畅批处理与撤销。** Builder 批量读取地形与放置方块，智能跳过纯空气区域，并有序记录操作日志以支持可靠的方块撤销。

### 任务执行更稳定

- **上游瞬时故障自动恢复。** 遇到 HTTP 502 等临时网络或网关抖动时，在未输出前会自动重试当前模型轮次，且绝不会重复执行已完成的游戏操作。
- **会话历史与设置可靠持久化。** 优化对话记录与设置写入逻辑，确保历史会话完整记录，最新配置随时生效。
- **移除不必要的词汇拦截。** 彻底移除了误伤正常游戏指令与物品名称的扫描改写逻辑，确保所有合法指令与模组物品名称原样传递。
- **按模型设置推理强度。** 可根据所用模型与服务商能力，灵活调整思考与推理强度。

### 兼容性说明

- 支持 Minecraft **26.2** 与 **Java 25**，分别提供 **Fabric** 与 **NeoForge** 下载包，两者均已内置 Minecraft Builder。
- OpenAllay 本体版本为 **0.3.0**，公共 Extension API 为 **0.2.2**，内置 Builder 为 **0.2.0**。
- 建议直接使用内置的 Builder；若此前曾单独安装过旧版本 Builder JAR，请先将其从 mods 文件夹中移除。
