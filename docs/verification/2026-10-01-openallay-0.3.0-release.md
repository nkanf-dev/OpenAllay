# OpenAllay 0.3.0 release verification

## Scope

OpenAllay 0.3.0 targets Minecraft 26.2 and Java 25 on Fabric and NeoForge. Public Extension API 0.2.2 is an independent compatibility contract. The bundled Builder is independently versioned 0.2.0 and explicitly accepts core `[0.3.0,0.4)` and API `[0.2.2,0.3)`.

## 502 evidence and recovery boundary

The latest manual trace showed one HTTP502 after 13 successful tools and another on a new request before any model turn or tool. A intervening continuation succeeded with larger internal request projections and provider-reported input usage of 51,016–52,283 tokens. Internal JSON size is not actual HTTP wire size; the retained trace has no response headers, partial-stream counters or emitting proxy identity. It does not prove a fixed input-size limit or identify the failing proxy/model hop.

Recovery is limited to a failed model round with no successful response progress. It reuses the same model request and never replays the Agent or completed tools. HTTP502/503/504 are typed temporary upstream failures; Retry-After and the captured failed-attempt deadline bound recovery. Successful response headers or any model output prevent automatic replay. Other known HTTP errors retain their actual status, even if an error body disconnects.

## Product and media

README was rewritten for player workflows. The new banner is true self-contained SVG geometry/path lettering with a reproducible PNG export; no embedded raster image or external font is used. Structural/render checks passed. The active model and attempted reviewer did not support image input, so actual visual/pixel acceptance is **not claimed**.

## Preserved boundaries and limits

Generic player-result scanning was removed. Framework credentials remain outside neutral prompt/config structures, and provider-private reasoning is excluded by typed boundaries. Full game data stays in request workspaces; model views are labelled and budgeted. Independent native Extension grants do not grant Agent JVM access.

Existing worlds, model configuration, credentials, history, journals and original exports were not reset. No additional paid-provider or fresh graphical acceptance run is counted as passed here. This file records local evidence; remote CI and release publication are separate receipts.
