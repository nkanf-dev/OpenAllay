# Archived early-development evidence

The Phase 3/4 delivery plans and verification directories are retired. They are
not current build gates or product feature boundaries. Their unique reports,
logs, screenshots, checksums, and original plans are retained outside Git in
`legacy-phase3-phase4-evidence-source-archive.zip`, with the 0.4.1 Minecraft-compatibility CI repair
evidence. The archive preserves the original relative paths and file bytes. The same
historical content remains available in Git history before this cleanup.

Historical references in dated release and verification reports describe the
files and commands used at the time. They are not instructions to restore the
retired gate. Current packaging uses distribution and SQLite checks; see the
[development guide](../development.md#verification).

## Recipe integration

Archived source: `docs/verification/phase-4c-all-known-recipes/`. It contains the
Fabric recipe-viewer report, redacted log, screenshots, and provenance for the
recorded JEI/REI/Farmer's Delight scenario. It does not prove a later artifact.
